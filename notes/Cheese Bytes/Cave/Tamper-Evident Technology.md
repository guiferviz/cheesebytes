Tamper-evident technology is a type of security design that does not prevent
tampering, but makes any unauthorised change visible and detectable.

A common example of tamper-evident technology is a wax seal on a letter. If the
seal is broken, it is clear that the letter has been opened and potentially
altered.

In the digital world, tamper-evident technology is often implemented using
cryptographic techniques. For example, digital signatures and hash functions can
be used to create tamper-evident tokens, such as [[JSON Web Token (JWT)]].
