This note describes my long-term life goals. It is not for profit or
recognition, but for the sheer joy of building and understanding.

- [[My Own Logical Computer]] — From gates to CPUs, even if only virtual. I want
  to truly understand what it means to compute from the ground up.
- **My Own Operating System** — From bootloader to shell. The code that runs the
  code and manages the hardware.
- **My Own Programming Language** — Design the syntax, invent the rules.
- **My Own (Large?) Language Model** — A mind built by me, token by token.
