This page invites you to experiment with various pseudo-random number generators
crafted in Python and watch as their outputs come to life in a dynamic
histogram.

As you dive into this adventure, you will discover that a well-crafted generator
will gracefully balance the bars over time, creating a harmonious distribution.
On the other hand, a less effective generator might reveal quirky patterns, with
some bars mysteriously absent.

Of course, this is not a statistical test; it is just a visual animation that
demonstrates what Marimo Islands can do in your browser!

```python {.marimo}
import anywidget
import traitlets

class StreamingHistogram(anywidget.AnyWidget):
    """
    Histograma en tiempo real de 0–1 usando la función global `rng()`.
    """
    _esm = r"""
    import * as d3 from "https://esm.sh/d3@7";
    export default {
      render({ model, el }) {
        const bins = model.get('bins');
        const margin = { top: 20, right: 20, bottom: 30, left: 40 };
        const width  = (model.get('width')  || 600) - margin.left - margin.right;
        const height = (model.get('height') || 350) - margin.top  - margin.bottom;

        // crea SVG
        const svg = d3.select(el).html('')
          .append('svg')
            .attr('width',  width  + margin.left + margin.right)
            .attr('height', height + margin.top  + margin.bottom)
          .append('g')
            .attr('transform', `translate(${margin.left},${margin.top})`);

        // función para dibujar con los datos actuales
        function draw(data) {
          const x = d3.scaleLinear()
            .domain([0, 1])
            .range([0, width]);
          const y = d3.scaleLinear()
            .domain([0, Math.max(1, d3.max(data))]).nice() // Asegura que el dominio comience en 0
            .range([height, 0]);

          const barWidth = width / bins * 0.99; // 90% del espacio para dejar un gap

          // BARRAS
          svg.selectAll('rect')
            .data(data)
            .join('rect')
              .attr('x',   (_d,i) => x(i / bins))
              .attr('width', barWidth)
              .attr('y',   d => y(d))
              .attr('height', d => height - y(d))
              .attr('fill', 'red')
              .attr('stroke', 'black') // borde negro
              .attr('stroke-width', 0.5); // grosor del borde

          // EJE X
          svg.selectAll('.x-axis')
            .data([null])
            .join('g')
              .attr('class','x-axis')
              .attr('transform', `translate(0,${height})`)
              .call(d3.axisBottom(x).ticks(bins));
          // EJE Y
          svg.selectAll('.y-axis')
            .data([null])
            .join('g')
              .attr('class','y-axis')
              .call(d3.axisLeft(y).ticks(5));
        }

        // al cambiar `data`, re-dibuja
        model.on('change:data', () => {
          draw(model.get('data'));
        }, this);

        // dibujado inicial
        draw(model.get('data'));

        // inicia el tick loop si `running`
        let timer = null;
        function start() {
          if (timer) return;
          timer = setInterval(() => {
            model.send({ event: 'tick' });
          }, model.get('interval') * 1000);
        }
        function stop() {
          clearInterval(timer);
          timer = null;
        }
        // arranca/parara según `running`
        model.on('change:running', () => {
          model.get('running') ? start() : stop();
        }, this);
        if (model.get('running')) start();
      }
    }
    """

    bins     = traitlets.Int(10).tag(sync=True)
    interval = traitlets.Float(0.15).tag(sync=True)
    running  = traitlets.Bool(True).tag(sync=True)
    data     = traitlets.List(traitlets.Int(), default_value=[0]*10).tag(sync=True)
    width    = traitlets.Int(500).tag(sync=True)
    height   = traitlets.Int(250).tag(sync=True)

    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self.data = [0] * self.bins
        self.on_msg(self._handle_tick)

    def _handle_tick(self, _, content, buffers):
        if content.get('event') == 'tick' and self.running:
            idx = int(rng() * self.bins)
            lst = list(self.data)
            lst[idx] += 1
            self.data = lst
```
