[Cheese Bytes](/) is already live! I just need to continue working on it to add
the missing parts I want to include.

This note lists all the features added during 2025 and 2026 that were not part
of the initial release (Initial features described in
[[Publishing Obsidian Notes in Astro]]).

- [x] Callouts with style. See [[Admonitions in Cheese Bytes]].
- [x] Ranking using fresh/medium/old cheeses. See [[Type of Notes]].
- [x] Marimo plugin. See any of these notes:
  - [[How Grid Choices Can Mislead Your Choropleth Maps]]
  - [[A Random Experiment with Marimo Islands]]
  - [[Marimo Iframe Notebook Test]]
- [x] List of linked pages: in and out links. See at the bottom of this page.
- [x] Improve content collection and speed up build time.
- [x] Wikilinks with aliases.
- [x] Web controls with keyboard. See [[CheeseBytes Vim Mode]].
  - `t` to change the theme.
  - `w` to toggle between wide and normal layout.
  - `s` to toggle the sidebar.
  - `f` to search for a note.
  - `?` to show the list of available controls. They are updated depending on
    the context (the components that are currently on focus).
- [x] Theme improvements.
- [x] Sidebar improvements: better styling, fixed main pages on top.
- [x] Wide layout.
- [x] Easter eggs ;)

I've also considered adding the following features, but I haven't decided yet:

- [ ] ToC on right hand panel. This might be useful to navigate long pages, but
      it might also be too much clutter on the UI. Also, big pages are a smell
      that they should be split into smaller pages, so maybe it's better to just
      do that instead of adding a ToC.
- [ ] Small note connectivity graph in right hand panel. Same as above, plus
      it's not very useful if we already have the list on links at the bottom of
      the page.
- [ ] Tag support. I don't really use tags, see
      [[How Cheese Bytes is Organized]].
